# 法务合同服务 容灾运行手册（DR_RUNBOOK）

> 服务：sm-legal-contract（端口 8026）

## 1. 数据库备份恢复步骤

1. 确认备份集：`sm_sm_legal_contract` 的最近一次全量 + WAL 增量备份。
2. 停止写入：将 Service 切到维护状态（摘除流量）。
3. 恢复：在目标实例执行 `pg_restore` 或 `wal-g backup-fetch` + `pg_resetwal` 重放。
4. 校验：表行数核对 + 抽样业务数据校验。
5. 恢复流量：滚动重启 Pod，确认连接池重建。
- RPO 目标：≤ 5 分钟（依赖 WAL 同步）；RTO 目标：≤ 1 小时。

## 2. 服务降级方案

- 非核心依赖（如统计、推荐）失败时，返回降级缓存或空结果，不阻塞主链路。
- 数据库压力过高时：限流（SM_RATE_MAX_REQUESTS）+ 只读模式 + 延迟非核心任务。
- 审计上报失败：本地落盘缓冲，恢复后补传，不得阻塞主交易。

## 3. 跨可用区 / 跨区域切换

- 跨可用区：Pod 反亲和已打散，单 AZ 故障由 HPA 在健康 AZ 补副本，自动恢复。
- 跨区域：DNS 切换 VIP 到备区域 ArgoCD Application，切换前同步镜像与数据库恢复点。
- 切换决策：P1 事件 + 主区域不可用超 30 分钟，由 DR 指挥下令。

## 4. 演练频率与记录

- 数据库恢复演练：每季度 1 次。
- Chaos（pod-kill）演练：每月 1 次（见 deploy/chaos/pod-kill-experiment.yaml）。
- 跨区域切换演练：每半年 1 次。
- 每次演练记录：日期、范围、结果、问题项、整改闭环人，归档至运维文档。
